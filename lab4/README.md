## Лабораторная работа №4

В лабораторной работе №4 был модернизирован сайт: главная страница свёрстана через Flexbox, каталог — через CSS Grid, а все цвета вынесены в переменные. Также добавлен градиент в шапке, реализована форма с нативной валидацией и JS-класс `FormData`, который при отправке формы создаёт объект и выводит его данные в консоль.
