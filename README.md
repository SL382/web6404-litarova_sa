В рамках лабораторной работы №2 разработан многостраничный web-сайт книжного магазина «Переплёт» на HTML и CSS. Сайт состоит из 4 страниц, содержит навигационное меню, изображения, таблицу с каталогом книг, а также использует отдельный CSS-файл с тремя видами селекторов и разным выравниванием в таблице.
